NPX Command Catalog

Execute standalone static hosting operations with zero local dependencies. Select any command below to inspect its live workflow, terminal outputs, and VPS options.

Core Provisioner

init <domain>

Creates the directory on Ubuntu, drops starter index.html, injects the Caddy file_server route, and reloads in one atomic step.

npx caddy-fileserver init call.keshavsoft.com
Audit & Diagnostics

check <domain>

Audits both Ubuntu disk directory existence and Caddy JSON configuration alignment to guarantee no 404 or misconfiguration.

npx caddy-fileserver check call.keshavsoft.com
Asset Generator

template <domain>

Generates standalone starter index.html and XML sitemap into any output directory without modifying your Caddy server config.

npx caddy-fileserver template call.keshavsoft.com ./dist
Inventory

list

Scans Caddy configuration for every active static file server and cross-checks whether its document root physically exists on disk.

npx caddy-fileserver list
