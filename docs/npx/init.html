Creates the Ubuntu filesystem document root, injects a production-grade starter template, and activates Caddy's native file_server route with auto-reload.

Simple NPX Command: auto-detects /etc/caddy/caddy.json & reloads

The 5 Atomic Steps Performed

  1. Provision Ubuntu Folder: Creates /usr/share/<domain> with standard permissions.
  2. Drop Starter Template: Injects a dark-mode, responsive index.html proving live traffic and disk read access.
  3. Inject Caddy Route: Configures standard subroute with vars root and file_server.
  4. Hot-Reload Caddy: Preserves existing TLS handshakes with zero downtime.
  5. Live HTTPS Verification: Probes https://<domain> to confirm 200 OK.
